# KeepTrackAppUI — Fitness & Macro Tracking Desktop App

A native Windows desktop application built with C# and WPF on .NET 8, designed to help users track nutritional intake, manage custom recipes, monitor supplement routines, and track body progress over time.

---

## Features

### User Module
- **Dashboard:** Centralized overview of daily macronutrient targets and logs.
- **Progress Tracking:** Log body metrics and visually monitor physical progress.
- **Recipes & Meal Management:** Save and organize custom recipes tailored to macro goals.
- **Supplement Log:** Track daily supplement usage and schedule schedules.
- **Account Security:** Full authentication suite including registration, login, email verification, and password change utility.

### Admin Management Suite
- **Admin Dashboard:** Overview of system activity and registered users.
- **User Management:** Manage accounts, access levels, and user statuses.
- **Global Catalog Management:** Create and curate global recipe and supplement libraries.
- **Progress Oversight:** View aggregated progress reports.

---

## Tech Stack

* **Language:** C#
* **Framework:** WPF (Windows Presentation Foundation)
* **Target Runtime:** .NET 8.0 (`net8.0-windows`)
* **IDE:** Microsoft Visual Studio / VS Code
